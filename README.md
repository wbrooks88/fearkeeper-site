# Fearkeeper website

WHAT THIS FOLDER IS FOR: the small public website for the Fearkeeper app,
served free by GitHub Pages. It holds the two pages the App Store listing
links to:

- Privacy Policy: `privacy/index.html` → https://wbrooks88.github.io/fearkeeper-site/privacy/
- Support: `support/index.html` → https://wbrooks88.github.io/fearkeeper-site/support/

`index.html` is a short front page, and `style.css` gives every page the
app's dark, lantern-lit look. `.nojekyll` tells GitHub Pages to serve the
files exactly as they are. Questions from players and GMs arrive as issues
in this repository.
